# Dimensões recomendadas para o portfólio

Os containers da seção **Nosso Portfólio** usam a proporção **9:16** (largura:altura).
Use imagens e vídeos verticais nessa proporção para que o conteúdo se encaixe
corretamente e não sofra cortes ou deformações.

## Tamanhos compatíveis

| Largura | Altura | Uso sugerido |
| ---: | ---: | --- |
| 360 px | 640 px | Arquivos leves para visualização em dispositivos móveis |
| 720 px | 1280 px | Opção recomendada para a maioria dos arquivos |
| 1080 px | 1920 px | Alta qualidade para imagens e vídeos |

Também são compatíveis outras dimensões que mantenham a mesma relação:

```text
altura = largura × 16 ÷ 9
```

Exemplos: `540×960`, `1440×2560` e `2160×3840`.

## Recomendações

- Mantenha o conteúdo principal afastado das bordas para evitar que textos ou
  elementos importantes fiquem próximos ao overlay do Instagram.
- Prefira arquivos verticais (9:16), evitando formatos quadrados ou horizontais.
- Para o overlay `PostSemFundo.png`, não redimensione ou edite o PNG; ele é
  aplicado separadamente sobre a mídia pelo CSS.
